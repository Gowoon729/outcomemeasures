# 아웃컴 메저 (치료사용 + 환자 설문)

- `index.html` : 치료사 앱 (환자 등록, 설문 보내기, 결과 가져오기, 전후 비교, 해석 기준)
- `survey.html` : 환자가 링크로 여는 설문 화면
- `catalog.json` : 관절별 설문지 목록 (status: ready=사용 가능, answers=답변만, pending=준비 중)
- `q/*.json` : 설문지 하나당 파일 하나 (문항, 보기 점수, 채점법, 출처 쪽수). 46종 수록
  - `scoring`이 없는 설문지는 답변만 저장 (원문에 채점법 없음)
  - `notes`에 원문과 다르게 보이는 부분을 '의견'으로 적어 두었음
- `survey-engine.js` : 설문 작성 화면 (환자 링크·현장 작성 공용)
- `common.js`, `style.css`, `manifest.json`, `sw.js`, `icon-*.png`

## 올리기
GitHub 새 저장소(예: outcome) → 압축 푼 폴더 안의 파일과 `q` 폴더를 모두 업로드 → Settings → Pages → main / (root) → Save
치료사 앱 주소: https://아이디.github.io/저장소이름/

## 설문지 추가
`q/새설문.json`을 추가하고 `catalog.json`의 해당 관절에 `{"id":"새설문","name":"이름","status":"ready"}`를 넣으면 됩니다.

## 구글 시트 팀 모드 (선택)
- `google-apps-script.gs` : 구글 시트(웹) → 확장 프로그램 → Apps Script 에 붙여넣고 `setup` 실행 → 웹 앱으로 배포(액세스: 모든 사용자).
- `sync.js` : 앱 설정 → 구글 시트 연결. 연결하지 않으면 아무 동작도 하지 않습니다(혼자 쓰기).
- 환자 링크에 `&s=<웹앱>&t=<내 id>` 가 붙어, 환자가 마치면 결과가 시트 inbox 로 자동 도착 → 앱이 동기화 때 가져와 저장.
- 시트는 팀원 키별로 기록을 나눠 저장하고, 키가 맞는 요청에만 해당 기록을 돌려줍니다. 관리자만 팀원 추가·삭제.

## 3단계: 설문지 추가 (설문지 탭)
- `editor.js` : 직접 만들기 / AI 변환 요청문 복사 → 붙여넣어 가져오기 / 점수 테스트·미리보기 / 저장
- 📨 내 설문지로 저장: 이 기기(`S.custom`)에 버전별로 저장, 시트 연결 시 `c:설문id`로 동기화. 점수 계산이 바뀌면 새 버전, 받은 결과는 작성 당시 버전으로 채점.
- 환자 링크: 시트 연결 + 올라간 상태면 짧은 링크(환자 폰이 시트에서 문항을 받음, `google-apps-script.gs` v3 재배포 필요), 아니면 문항을 압축해 링크(`&d=`)에 포함.
- 📚 모두에게 게시: 설정에서 GitHub 토큰(Fine-grained, Contents 읽기/쓰기)을 넣은 기기에서만. `q/파일.json` + `catalog.json`을 갱신.
